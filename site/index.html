Why Operon exists

A model can generate text.
An app needs it to do real work.

Small models are fast, private, inexpensive, and increasingly capable. But a model alone does not remember what matters, know your app state, call capabilities safely, or prove that its answer is grounded. Operon supplies that missing layer.

01 Model alone

A convincing answer—without reliable state or authority.

  • Reconstructs context from chat prose
  • Guesses when arguments are missing
  • Can produce valid-looking but unusable output
02 Model + Operon

A bounded execution—using typed context, app-owned skills, and evidence.

  • Resolves references from structured session state
  • Clarifies missing input before acting
  • Returns validated output, receipts, and a trace

See the difference

Same local model.
Different system.

A model alone only generates the next response. Operon gives that model typed state, app-owned capabilities, evidence rules, and bounded outcomes.

A full local harness

The pieces real
AI products need.

Operon keeps language interpretation in the model and truth, permissions, state, and side effects in your application.

CTX

Typed session context

Carry the active object, view, draft, or previous result across turns without asking the model to rediscover it from prose.

MEM

Scoped durable memory

Retrieve app-approved facts and preferences by namespace, subject, sensitivity, validity, and status. Models never gain write authority.

SKL

Host-controlled skills

Expose typed capabilities with schemas, artifact dependencies, confirmation requirements, and app-owned code.

GRF

TaskGraph execution

Compile consumes/produces edges into a ready set and refuse success until the completion contract is satisfied.

RCP

Receipts & recovery

Record idempotent skill receipts and restore a versioned snapshot without replaying completed work.

VAL

Validation & repair

Enforce typed output, provenance, citations, confidence, and application rules before a result reaches the user.

EVD

Verifiable evidence

Require claim-level quotes, check exact substrings locally, derive byte offsets, and abstain when the contract cannot be met.

INT

Interruptible by design

Stream provisional output, cancel when the app backgrounds, and measure model-call latency, tokens, thermal state, and low-power state.

Upgrade your model with Operon ↗
local terminal
from operon import Operon, Policy, LocalDocuments

# Start with the model already in your app
runtime = Operon.wrap(your_existing_model)
result = runtime.run("Help me plan my day")

# Add verifiable local knowledge without replacing it
runtime = Operon.wrap(
  your_existing_model,
  grounding=LocalDocuments("./knowledge"),
  policy=Policy(grounding_mode="extractive"),
)
result = runtime.run("What does the policy require?")
print(result.status, result.claims)
